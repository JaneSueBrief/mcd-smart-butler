## 项目介绍

### 这是什么

「麦门超级管家」是一个基于**麦当劳官方 MCP 服务**开发的智能点餐助手。
它把麦当劳 MCP 提供的 35 个原子工具，编排成一条**普通用户能走完的点餐路径**。

### 解决什么问题

麦当劳 MCP 的原始能力对普通用户门槛很高：

- 想省钱，得自己在「本店券 / 麦麦省可领券 / 卡包已有券」三个来源之间比价
- 想看热量，得先知道营养表里只有单品、套餐得自己拆开累加
- 券会过期、积分会过期，但没人提醒你
- 价格和库存随时变，上次查的数可能今天就不对了

这个项目把这些都接了过来：**你只管说要什么，剩下的我来算、我来比、我来提醒。**

### 核心能力

| 能力 | 说明 |

| 🥗 营养方案 | 按人群（成人/儿童/健身/控脂/控糖）配，套餐拆单品累加 |

## 安装方法

### 前置条件

需要一个**麦当劳中国 MCP Token**（你自己的，本项目不共享任何公共凭证）。

### 步骤

**1. 获取 Token**

打开 https://open.mcd.cn/mcp/doc ，右上角扫码登录 →
点「控制台」→ 激活 → 同意协议 → 复制 Token。

> 装好本 Skill 后，跟我说一声，我会**帮你把授权页打开**，你在页面上点几下就行。

**2. 配置 MCP**

在客户端 `~/.workbuddy/mcp.json` 里加上：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": { "Authorization": "Bearer YOUR_MCP_TOKEN" }
    }
  }
}
```

**3. 替换占位符**

把 `YOUR_MCP_TOKEN` 换成你复制的 Token，重启客户端。

**4. 验证**

跟我说"想吃麦当劳"，我会先做一次授权探活，通了就继续。

### 安全说明

- **没配 Token 会怎样**：我会立刻停下，主动告诉你去哪配，不会调用任何麦当劳接口
- **扫码、点激活、复制 Token 这三步必须你自己做**——涉及账号登录，我不代劳，也不索取你的 Token 值
- **你的 Token 等于账号登录态**，本项目永不回显、永不写入任何文件

## 使用示例

### 示例 1：省钱党

> **你**：帮我算算麦当劳怎么点最省

> **管家**：好嘞，两个事：
> 1. 去哪家店？说个大概位置我帮你找最近的
> 2. 自取还是外送？自取便宜些

> **你**：某某路附近，自取

> **管家**：你附近有两家店，早餐开门时间差挺多……
>
> **明早早餐 · 三个方案**
>
> **方案 1｜最省 ¥11.90** ⭐
> 　一早现磨 超值二件套（吉士蛋麦满分 + 麦咖啡冰美式中杯）
>
> **方案 2｜更饱 ¥19.90**
> 　麦满分单人餐（吉士蛋麦满分 + 脆薯饼 + 饮品）
>
> **方案 3｜咖啡更好 ¥24.90**
> 　猪柳蛋美式组合
>
> 三家都有 ¥3 立减券自动抵扣。**自取比外送省 ¥8.80**。
> 你挑一个，或者告诉我别的偏好？

### 示例 2：健身减脂

> **你**：我在减脂，来个低卡的

> **管家**：是给你自己吃，还是给小朋友？有没有要特别注意的（比如健身、控糖）？

> **你**：自己，减脂

> **管家**：「苹板」支撑Pro套餐
> **476 kcal ｜ 蛋白 25g ｜ 脂肪 18g ｜ 钠 1077mg**
> 按减脂（400–550 kcal、蛋白 ≥25g）判定：**双达标** ✅
> 明细：板烧鸡腿堡 391 kcal ｜ 玉米杯(小) 53 kcal ｜ 苹果片 32 kcal ｜ 无糖可乐 0 kcal

### 示例 3：领券提醒

> **你**：随便看看有啥优惠

> **管家**：你麦麦省里躺着 2 张没领的券，我帮你一键领了？（不领就过期了）
>
> · 满 30 减 5 券（11 月 15 日到期）
> · 早餐立减 3 元券（10 月 31 日到期）

### 示例 4：下单（需你明确说"下单"）

> **你**：就方案 1，下单

> **管家**：念一遍你确认下：
> 　门店：麦当劳XX路餐厅
> 　方式：到店自取
> 　餐品：一早现磨 超值二件套
> 　时间：明早 08:00
> 　用券：下单立减 3 元券 -¥3.00
> 　**实付：¥11.90**
>
> 没问题我就下单了？

> **你**：可以

> **管家**：✅ 下单成功
> 　取餐门店：麦当劳XX路餐厅
> 　**取餐码：XXXXX**
> 　付款链接：（15 分钟内有效）
>
> 付完款就能去取啦。
